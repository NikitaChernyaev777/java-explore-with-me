# ExploreWithMe

**ExploreWithMe** — это дипломный проект, представляющий собой приложение-афишу, в котором пользователи могут:
- предлагать события (от выставок до походов в кино),
- находить единомышленников,
- регистрироваться на мероприятия,
- и делиться комментариями.

Проект разделён на два сервиса:
- **Основной сервис** — обрабатывает данные о пользователях, событиях и действиях.
- **Сервис статистики** — фиксирует количество просмотров и предоставляет агрегированные данные.

---

## Возможности приложения

- Поиск событий и фильтрация по параметрам.
- Регистрация и управление своими событиями.
- Подача и подтверждение заявок на участие.
- Модерация событий и подборок администратором.
- **Дополнительная фича: комментарии к событиям**

---

## Архитектура доступа к API

API основного сервиса делится на три части:

| Часть         | Кто имеет доступ     | Основные действия                                |
|---------------|----------------------|--------------------------------------------------|
| **Public**    | Все пользователи     | Поиск, просмотр событий, комментарии (GET)       |
| **Private**   | Авторизованные       | Создание, редактирование, удаление событий/комментариев |
| **Admin**     | Администраторы       | Модерация пользователей, категорий, событий и комментариев |

---

## Основные эндпоинты

### События (по спецификации)
- `GET /events` — поиск событий с параметрами
- `GET /events/{eventId}` — подробности события
- `POST /users/{userId}/events` — создание события
- `PATCH /users/{userId}/events/{eventId}` — обновление
- `GET /users/{userId}/events` — просмотр собственных
- `PATCH /admin/events/{eventId}` — публикация/отклонение
- `POST /users/{userId}/requests` — подача заявок

и другие...

---

## Сервис статистики

Сервис логирует:
- количество просмотров события
- доступ к спискам событий и детальной информации

Данные статистики используются при сортировке событий по популярности.

---

## Дополнительная функциональность: Комментарии к событиям

Добавлена фича, позволяющая пользователям оставлять комментарии к событиям, а администраторам — модерировать их.

### PRIVATE (для авторизованных пользователей)
- `POST /users/{userId}/events/{eventId}/comments` → создание комментария к опубликованному событию
- `PATCH /users/{userId}/events/{eventId}/comments/{commentId}` → редактирование своего комментария
- `DELETE /users/{userId}/events/{eventId}/comments/{commentId}` → удаление своего комментария

### PUBLIC (доступен всем)
- `GET /events/{eventId}/comments` → получение списка комментариев к событию с пагинацией
- `GET /events/{eventId}/comments/{commentId}` → получение конкретного комментария по ID

### ADMIN (доступен только администраторам)
- `PATCH /admin/events/{eventId}/comments/{commentId}` → редактирование любого комментария
- `DELETE /admin/events/{eventId}/comments/{commentId}` → удаление любого комментария
