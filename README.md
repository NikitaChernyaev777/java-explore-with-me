# 🌍 ExploreWithMe

**ExploreWithMe** — это микросервисное приложение для поиска и организации событий. Оно разделено на два сервиса: основной и сервис статистики.

---

## 💡 Идея

Свободное время — ценный ресурс.  
Ежедневно мы решаем, как его провести: пойти в кино, на выставку или концерт. Самое сложное — найти единомышленников и договориться.  

**ExploreWithMe** решает эту задачу:  
- пользователи создают события (от похода в кино до масштабного фестиваля),  
- находят тех, кто хочет присоединиться,  
- обсуждают события через комментарии,  
- а сервис статистики помогает выявлять самые популярные активности.  

---

## 🏗 Архитектура проекта

Приложение разделено на два независимых сервиса:

- **Основной сервис**  
  Управляет пользователями, событиями, заявками и комментариями.  
  API имеет три уровня доступа:  
  - `Public` — поиск и просмотр событий, категорий, подборок и комментариев.  
  - `Private` — управление своими событиями, подача заявок, добавление/редактирование комментариев.  
  - `Admin` — модерация пользователей, категорий, подборок, событий и комментариев.  

- **Сервис статистики**  
  Фиксирует обращения к публичным эндпоинтам и хранит данные о просмотрах.  
  Позволяет строить аналитику и сортировать события по популярности.

---

## ✨ Возможности

- 🔎 Поиск и фильтрация событий по дате, категории или популярности.  
- 📝 Создание и редактирование собственных событий.  
- 🤝 Подача и подтверждение заявок на участие.  
- 🛠 Модерация событий, категорий и подборок администратором.  
- 💬 **Комментарии к событиям**:  
  - пользователи могут оставлять и редактировать свои комментарии,  
  - администраторы модерируют содержимое.  
- 📊 Сбор и анализ статистики просмотров.  

---

## 🔌 Основные эндпоинты

### События
- `GET /events` — поиск событий  
- `GET /events/{eventId}` — подробности события  
- `POST /users/{userId}/events` — создать событие  
- `PATCH /users/{userId}/events/{eventId}` — обновить событие  
- `GET /users/{userId}/events` — события пользователя  
- `PATCH /admin/events/{eventId}` — публикация/отклонение  
- `POST /users/{userId}/requests` — подача заявки  

### Комментарии
- `POST /users/{userId}/events/{eventId}/comments` — добавить комментарий  
- `PATCH /users/{userId}/events/{eventId}/comments/{commentId}` — редактировать свой  
- `DELETE /users/{userId}/events/{eventId}/comments/{commentId}` — удалить свой  
- `GET /events/{eventId}/comments` — список комментариев  
- `GET /events/{eventId}/comments/{commentId}` — конкретный комментарий  
- `PATCH /admin/events/{eventId}/comments/{commentId}` — редактировать любой  
- `DELETE /admin/events/{eventId}/comments/{commentId}` — удалить любой  

---

## 📊 Сервис статистики

- фиксирует обращения к публичным эндпоинтам,  
- хранит данные о просмотрах событий и категорий,  
- предоставляет статистику за выбранный период по конкретным эндпоинтам.  

Пример: сортировка событий по популярности.
